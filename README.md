# AI Resume Analyzer

## 📌 Overview

AI Resume Analyzer is a web-based application that analyzes resumes and provides insights such as skills, recommendations, and improvements using machine learning and NLP techniques.

---

## 🚀 Features

- Resume upload and analysis
- Skill extraction from resumes
- Basic recommendations for improvement
- User-friendly interface

---

## 🛠️ Technologies Used

- Python
- Flask
- Machine Learning (NLP)
- MySQL
- HTML/CSS

---

## ⚙️ Installation Steps

1. Clone the repository:

   ```
   git clone https://github.com/deepakpadhi986/AI-Resume-Analyzer.git
   ```

2. Navigate to project folder:

   ```
   cd AI-Resume-Analyzer
   ```

3. Create virtual environment:

   ```
   python -m venv venv
   ```

4. Activate virtual environment:

   ```
   source venv/Scripts/activate
   ```

5. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

6. Setup MySQL database:

   ```
   CREATE DATABASE cv;
   ```

7. Run the application:

   ```
   python app.py
   ```
